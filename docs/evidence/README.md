# Evidence index

This directory stores sanitized, reproducible proof for Portionly integrations and releases.

Evidence must not contain private keys, API tokens, passkey secrets or unredacted personal data.

Expected records:

- provider capability and package-version checks
- contract bytecode hashes and ABI provenance
- RED/GREEN test logs
- deployment simulation and mainnet receipts
- APK checksum and physical-device test result
- final release gate output

# One passkey, a wallet per person, 2026-10-10

Shown on a physical Android phone with the 0.3.0 build. One Mera passkey derives the main wallet (BIP 44 index 0) and a separate wallet for each saved person (index 1 and up), as Mera's guide recommends for additional accounts.

- Main wallet (index 0): `0x090751B927929872b16f6078492c5585A2e8D830`
- Wallet kept for the person "Joy" (index 1): `0xF8603788F521f71Cfc484268eDb6B80265b780e9`
- Set aside: 0.5 AUSD moved from the main wallet to Joy's wallet, with 0.3 MON for fees: `0x2987c067875d…` (block 112200077)
- Paid from Joy's wallet to her recipient address `0x42e0dDf73e2275e7F41B22Cf9c587ADDA3C1B7D2`: `0x4da542b4d717cfc85643809e3f3884f14c138336d02aee45a62ddec4ceafb4d5`

Both wallets were opened by the same fingerprint in one unlock. The indexer shows the payment's sender as Joy's wallet, not the main wallet, so the recipient sees only the wallet that pays them.
